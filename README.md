# ktx-macro

지정한 날짜·구간·시간대에서 KTX **지정석**(일반실/특실)이 나올 때까지 조회하고, 나오면 예약까지 시도하는 스크립트입니다. 결제는 하지 않습니다. 예약 후 코레일톡/홈페이지에서 직접 결제하세요.

## 현재 동작

- KTX / KTX-산천만 대상 (무궁화호 제외)
- **입석, 입석+좌석은 예약하지 않음.** 지정석이 뜰 때만 예약
- 출발 시각 범위 + 도착 시각 상한(`--arrive-before`) 필터
- 지정석이 나올 때까지 반복 조회 (기본 간격 8초, `--max-attempts 0`이면 무제한)
- 일반실 우선, 없으면 특실
- 인원 지정 가능: 어른/청소년/어린이/경로/유아, 총 1~9명 (기본 어른 1명)

구버전 `korail2`는 코레일이 `MACRO ERROR`로 로그인을 막습니다. 지금은 코레일톡 앱 API를 쓰는 [`korail-mobile-api`](https://github.com/yakisoba0728/korail-mobile-api)를 사용합니다.

[k-skill](https://github.com/NomaDamas/k-skill)의 `ktx-booking`은 현재 **공식 시간표 조회 전용**이라 로그인·실시간 좌석·예약은 하지 않습니다.

## 설치

```bash
git clone https://github.com/comflife/ktx-macro.git
cd ktx-macro
pip install -r requirements.txt
```

Python 3.11 이상이 필요합니다.

## 계정 설정

프로젝트 폴더에 `.env`를 만듭니다. 이 파일은 `.gitignore`에 들어 있어 **git에 올라가지 않습니다.**

```
KORAIL_ID=회원번호_또는_이메일_또는_01012345678
KORAIL_PW=비밀번호
```

- 휴대폰은 `01012345678`처럼 숫자만, 또는 `010-1234-5678` 모두 됩니다 (실행 시 숫자만 쓰도록 정규화)
- 비밀번호에 `$`가 있어도 그대로 읽습니다
- 예시 파일은 `.env.example`입니다. 실제 아이디/비밀번호는 `.env`에만 넣으세요

## 실행 (화면)

명령어가 어려우면 Streamlit 화면을 쓰세요. `requirements.txt`에 포함되어 있어 별도 설치는 필요 없습니다.

```bash
streamlit run app.py
```

브라우저가 자동으로 열립니다. 열리지 않으면 터미널에 표시된 `http://localhost:8501` 주소로 접속하세요.

### 화면 구성

화면은 위에서 아래로 공통 조건 → 좌우로 나뉜 구간 조건 → 인원 → 시작/중지 → 로그 순서입니다.

| 위치 | 항목 | 설명 |
|------|------|------|
| 왼쪽 사이드바 | 코레일 아이디 / 비밀번호 | `.env`에 넣어두면 자동으로 채워집니다. 입력값은 어디에도 저장되지 않습니다 |
| 상단 | 출발역 / 도착역 | 역 이름을 그대로 입력. 기본값 수서 → 부산 (아래 주의 참고) |
| **왼쪽 칸: 가는 편** | 출발역 → 도착역 | 이 구간 예약 체크, 날짜, 출발 시작/종료, 도착 기한 |
| **오른쪽 칸: 오는 편** | 도착역 → 출발역 | 왼쪽과 같은 항목. 역은 자동으로 뒤집힙니다 |
| 하단 | 인원 | 어른 / 청소년 / 어린이 / 경로 / 유아. 두 구간 공통, 합계 1~9명. 기본값 어른 2, 어린이 1 |
| 고급 설정 | 조회 간격 | 기본 8초. 왕복이면 한 주기에 두 번 조회합니다 |
| 고급 설정 | 최대 조회 횟수 | `0`이면 지정석이 나올 때까지 계속 |
| 고급 설정 | 조회만 | 예약하지 않고 한 번만 조회해서 결과를 보여줍니다 |

### 왕복 동작

- 가는 편과 오는 편을 둘 다 켜면 **한 번의 로그인 세션**에서 두 구간을 번갈아 조회합니다. 계정 하나로 두 번 로그인하지 않으므로 세션이 꼬이지 않습니다.
- 한쪽이 먼저 잡히면 그 구간은 예약 완료로 두고, 남은 구간만 계속 찾습니다. 먼저 잡힌 예약은 **구입기한 안에 결제**해야 하니 로그와 화면의 기한을 확인하세요.
- 편도만 원하면 한쪽의 "이 구간 예약" 체크를 끄면 됩니다.
- 기본 날짜는 가는 편 내일, 오는 편 모레입니다.

### 사용 순서

1. 사이드바에 계정을 확인합니다.
2. 출발역과 도착역을 넣습니다. 오는 편 방향은 자동으로 바뀝니다.
3. 왼쪽(가는 편)과 오른쪽(오는 편)에 각각 날짜와 시간대를 넣습니다. 필요 없는 쪽은 체크를 끕니다.
4. 인원을 넣고 **▶ 시작**을 누릅니다. 입력이 잘못되면 로그인 시도 없이 빨간 오류 메시지가 뜹니다.
5. 실행 중에는 입력칸이 잠기고, 아래 로그가 1초마다 갱신됩니다. 구간별 예약 상태가 좌우로 표시됩니다.
6. 지정석이 잡히면 해당 구간에 초록색 **예약 완료**와 **구입기한**이 뜹니다. 그 시각 안에 코레일톡/홈페이지에서 결제하세요.
7. 언제든 **■ 중지**를 누르면 대기 시간을 기다리지 않고 바로 멈춥니다.

### 시작 전에 걸러주는 것

- 계정, 출발역, 도착역이 비어 있거나 두 역이 같을 때
- 가는 편과 오는 편이 둘 다 꺼져 있을 때
- 어느 구간이든 출발 시작 시각이 종료 시각보다 늦을 때
- 오는 편 날짜가 가는 편보다 빠르거나, 같은 날인데 오는 편 출발이 가는 편보다 빠를 때
- 인원 합계가 0명이거나 10명 이상일 때
- 유아 수가 보호자(어른 + 경로) 수보다 많을 때

### 결과 상태

| 표시 | 의미 |
|------|------|
| ✅ 모든 구간 예약 완료 | 켜둔 구간이 전부 잡혔습니다. 구입기한 안에 결제하세요 |
| 일부 구간만 예약됐습니다 | 한쪽만 잡힌 채 끝났습니다 (중지 또는 최대 횟수). 잡힌 쪽은 결제하세요 |
| ⏹ 사용자가 중지했습니다 | 아무것도 잡히기 전에 중지 버튼으로 멈췄습니다 |
| 조회를 마쳤지만 예약하지 않았습니다 | 조회만 모드였거나 최대 횟수에 도달했습니다 |
| ❌ 오류 | 로그인 실패 등. 로그에 원인이 나옵니다 |

## 인원 구분

| 항목 | 기준 | 좌석 | 운임 |
|------|------|------|------|
| 어른 | 만 13세 이상 | 있음 | 정상 |
| 청소년 | 만 13~18세 (청소년 할인 대상) | 있음 | 할인 |
| 어린이 | 만 6세 이상 13세 미만 | 있음 | 어른의 50% |
| 경로 | 만 65세 이상 | 있음 | 할인 |
| 유아 | 만 6세 미만 | **없음** (보호자가 안고 탑승) | 무임 |

- **어린이와 유아는 다릅니다.** 유아에게 좌석을 주고 싶으면 어린이로 넣으세요.
- 유아는 보호자 1명당 1명까지입니다.
- 조회는 좌석이 필요한 인원(유아 제외)만큼 자리가 있는 열차를 찾고, 예약은 유아까지 포함한 전체 인원으로 요청합니다.

## 실행 (명령어)

```bash
python ktx_macro.py --date 20260827 --dep 대전 --arr 서울 --start-time 160000 --end-time 163000 --arrive-before 180000
```

| 옵션 | 설명 | 기본값 |
|------|------|--------|
| `--date` | 날짜 `YYYYMMDD` | 필수 |
| `--dep` / `--arr` | 출발역 / 도착역 | 필수 |
| `--start-time` | 출발 시작 시각 `HHMMSS` 또는 `HH:MM` | `080000` |
| `--end-time` | 출발 종료 시각 | `235959` |
| `--arrive-before` | 이 시각 **전** 도착만 | 없음 |
| `--adult` | 어른 인원 | `1` |
| `--teen` / `--child` / `--senior` | 청소년 / 어린이 / 경로 인원 | `0` |
| `--infant` | 동반 유아 인원 (좌석 없음) | `0` |
| `--interval` | 조회 간격(초) | `8` |
| `--max-attempts` | 최대 조회 횟수. `0`이면 지정석이 나올 때까지 | `0` |
| `--search-only` | 예약하지 않고 한 번만 조회 | 꺼짐 |

조회만 하려면:

```bash
python ktx_macro.py --date 20260827 --dep 대전 --arr 서울 --start-time 160000 --end-time 163000 --arrive-before 180000 --search-only
```

인원은 `--adult 2 --child 1`처럼 지정합니다. 합계는 1~9명이어야 하며, 조회와 예약 모두 이 인원 기준으로 이루어집니다.

간격을 바꾸려면 `--interval 3`처럼 붙이면 됩니다. 너무 짧게 치면 차단될 수 있습니다.

중지: `Ctrl+C`

예약되면 비프음이 나고, **구입기한 안에 코레일톡/웹에서 결제**해야 합니다. 결제하지 않으면 예약이 풀립니다.

## 주의

- 개인 사용, 본인 계정, 본인 책임입니다. 코레일 약관에 걸릴 수 있습니다.
- 결제는 자동화하지 않습니다 (예약까지).
- 코레일 안티매크로가 바뀌면 다시 실패할 수 있습니다.
- **수서역은 SRT 전용 역입니다.** 이 매크로는 코레일 KTX만 조회·예약하므로 수서 출발은 열차가 잡히지 않을 수 있습니다. SRT는 SR(SRT 앱)에서 별도로 예약해야 하며, 코레일 계정으로는 예약할 수 없습니다. KTX로 부산에 가려면 서울역이나 용산역 출발을 쓰세요.
